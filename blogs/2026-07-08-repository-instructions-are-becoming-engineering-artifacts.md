Your team already treats CI config, dependency manifests, and policy files as things that need an owner, a review, and a drift check, because they shape the code you ship. Repository instruction files like CLAUDE.md , AGENTS.md , and . cursorrules now do the same job: coding agents read them to decide how to generate, modify, and review code.
